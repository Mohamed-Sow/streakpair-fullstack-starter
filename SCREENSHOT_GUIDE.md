## How to Capture Screenshots

### Option 1: Using Vibecode App
1. Navigate to each screen
2. Use your device's screenshot function:
   - **iOS**: Press Side Button + Volume Up
   - **Android**: Press Power + Volume Down
3. Screenshots will save to your Photos/Gallery

### Option 2: Using iOS Simulator (if building)
1. Open simulator
2. Navigate to screen
3. Go to **File > New Screen Shot** (Cmd+S)
4. Saves to Desktop

### Option 3: Using Android Studio (if building)
1. Open emulator
2. Navigate to screen
3. Click camera icon in emulator toolbar
4. Saves to Screenshots folder

## Screenshot Tips

### Design Tips
- ✅ Use realistic data (not "Test" or "Example")
- ✅ Show active usage (check-ins completed, streaks alive)
- ✅ Display variety (different emojis, streak types)
- ✅ Include competition mode examples
- ✅ Show notifications/badges if present
- ✅ Capture during "golden hour" UI time (e.g., show "Good evening" greeting)

### Technical Tips
- ✅ Take screenshots in portrait orientation
- ✅ Ensure proper resolution (use actual device/simulator)
- ✅ No status bar issues (battery, time, carrier)
- ✅ Hide personal information
- ✅ Check for typos or errors in UI
- ✅ Ensure good lighting/contrast

### Content Tips
- Create 3-4 sample streaks with different:
  - Emojis (🔥, 💪, 📚, 🏃)
  - Names ("Morning Workout", "Read Daily", "Meditation")
  - Progress levels (some completed, some pending)
  - Include 1-2 competition mode streaks

## After Capturing Screenshots

### Edit and Optimize
1. Crop to exact required dimensions
2. Add text overlays if desired (optional)
3. Compress for faster loading
4. Ensure all screenshots are the same aspect ratio

### Upload Order
Arrange screenshots in this order:
1. Home Screen (main value prop)
2. Streak Detail (shows depth)
3. Competition Mode (unique feature)
4. Check-In (core action)
5. Calendar/Progress (results)
6. Create Streak (flexibility)
7. Profile (personal stats)
8. Welcome (branding)
